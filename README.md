# Cynthia Wong — Projects

The landing page for my projects: **[cynthiawongss.com](https://cynthiawongss.com)**

Each project lives in its own repo. Ones with a live demo are served from GitHub Pages at `cynthiawongss.com/<repo-name>/`.

To add a project, copy one of the `<article class="card">` blocks in `index.html` and fill in the name, description and links.
